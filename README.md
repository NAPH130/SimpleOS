# SimpleOS

SimpleOS 是一个面向操作系统课程实践的教学项目，计划通过逐步实现最小内核、内存管理、任务调度等功能，理解操作系统各部分如何协作。

## 当前状态

项目目前只有文档和目录骨架，尚未实现可启动内核、构建脚本或运行命令。目录中的 `.gitkeep` 仅用于让 Git 保留空目录，不代表相应功能已经完成。

拟采用 x86_64、C++ 与少量汇编，并在 QEMU 中运行。具体引导方式和构建工具链将在实现最小内核时确定；课程对 MBR 的要求也需要结合实际验收方式核对。

## 项目目录

```text
src/           项目源码
  boot/        引导配置与启动入口
  arch/x86_64/ x86_64 架构相关机制
  kernel/      内核初始化及核心服务
  drivers/     设备驱动
  mm/          内存管理
  task/        任务、进程及调度
  sync/        同步机制
  fs/          文件系统
  loader/      用户程序装载
  lib/         内核基础工具
  user/        用户态基础库与应用
include/       各模块头文件
tests/         各子系统的功能测试
scripts/       构建、运行及调试辅助脚本
docs/          项目需求、设计和结构说明
steps/         分阶段实施指南
TEMP/          现有参考实验材料
build/         本地构建产物（生成后不纳入版本管理）
```

目录职责和开发顺序详见 [项目目录结构说明](docs/项目目录结构说明.md)。现有需求和实施文档描述的是规划，功能与命令须以实际代码为准。
