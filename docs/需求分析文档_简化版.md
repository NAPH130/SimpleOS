# SimpleOS 需求分析文档 (精简速查版)

---

## 1. 项目定位与核心差异
- **定位**：面向全生命周期、工程一体化的现代 C++ 单体操作系统（SimpleOS），非分片独立 Demo。
- **目标指令集架构 (ISA)**：**x86_64**（直接匹配宿主机 CPU：AMD Ryzen 7 9700X，契合实验大纲对 `Bootloader (MBR)` 的原生要求，原生工具链构建，免除交叉编译烦恼）。
- **加分项主打策略**：以 **GUI 图形界面（VBE Framebuffer 2D 桌面引擎）** 为主打高端展示项，多核 SMP、网络栈与安全防护作为待选备用项。
- **与参考实验差异**：
  - *参考实验 (GardenerOS/rCore)*：Rust 编写、多项目分散、各章节代码独立孤立、偏向脚本化教学。
  - *本项目 (SimpleOS)*：**现代 C++ (Freestanding C++17/20)** 编写、统一代码库、阶梯递进演进、工程化模块高内聚低耦合。

## 2. 评分对齐与指标分解 (满分 60 分)

```
[基本功能 (48分)] : 6次实验 × 8分 (代码运行4分 + 文档陈述3分 + 答辩抗干扰1分)
        │
        ├── 阶段1: 环境搭建与最小内核 (x86_64 裸机 MBR 引导, 汇编入口, 自研kprintf)
        ├── 阶段2: 特权级与系统调用 (Ring 0/Ring 3 切换, IDT/TrapFrame, sys_write/exit)
        ├── 阶段3: 内存管理 (内核/用户空间划分, 动态分区, 二进制拷贝加载, CR3分页)
        ├── 阶段4: 任务多道与分时调度 (PCB, switch_to 上下文切换, yield协作 + PIT时钟抢占)
        ├── 阶段5: 同步互斥与仿真 (自旋锁, 信号量P-V, 银行存取款数据竞争/加锁对比)
        └── 阶段6: 文件系统与ELF (只读文件系统, ELF64 Header/ProgramHeader解析运行)
        │
[进阶加分 (6分)]  : 6次实验 × 1分 (在圈子内深度拓展)
        └── 伙伴系统(Buddy) + MLFQ调度 + 扩展POSIX系统调用(fork/exec/wait) + 银行家算法
        │
[高端加分 (6分)]  : 超出原有圈子 (满分攻坚项目)
        ├── 【核心主打加分项】: GUI 2D 桌面与可视化监控 (VBE Framebuffer + 动态图表 + 时钟)
        └── 【待选备选加分项】:
            ├── S (Security)   : CR0/CR4 与页表 U/S 位硬件隔离 + copy_from_user 边界防御
            ├── P (Parallel)   : x86 多核 SMP 启动 (Local APIC 唤醒从核) + 自旋锁调度
            └── D (Dist/Net)   : VirtIO-Net 虚拟网卡 + ARP/IPv4/ICMP Ping网络回显
```

## 4. 高端加分项重点聚焦 (GSP/D)

1. **G (GUI)**：在 QEMU 窗口中直观展示图形画面（点、线、矩形、文字、时钟/监视器控件），答辩演示效果极其惊艳。
2. **S (Security)**：内核态地址空间禁止用户态访问（硬件页表 MMU 强隔离），系统调用拦截越界野指针攻击。
3. **P (SMP)**：同时启动 2~4 个 CPU 核心，Per-CPU 运行队列，多核抢占互斥自旋锁。
4. **D (Network)**：VirtIO-Net 驱动收发包，在宿主机上执行 `ping 192.168.x.x` 可收到 SimpleOS 内核的 ICMP Reply 应答。
5. **交互 Shell 终端**：提供命令提示符 `SimpleOS# `，支持 `ps`, `ls`, `cat`, `bank_test`, `gui`, `help` 等交互式演示。
