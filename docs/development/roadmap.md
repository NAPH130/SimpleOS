# 开发路线与阶段验收

当前基线是 Limine BIOS 启动、串口控制台和内核态 `int3` 自检。以下阶段目标用于安排开发，每一阶段准备可观察的运行结果。 [构建、运行与验证](../guides/getting-started.md)

## 近期任务

1. **补充 CPU 异常诊断。** 先注册第 6 号向量 `#UD`，复用 `TrapFrame`。用独立自检执行 `ud2`，验证内核打印异常名称、向量号和 `RIP` 后停机。日常启动保留 `int3` 的正常返回自检。
2. **处理 CPU 自带错误码的异常。** 扩展 `#GP` 或 `#PF` 的汇编入口，在分发函数中确认向量号、硬件错误码和返回现场能正确读取。
3. **运行首个用户态程序。** 设置用户态代码段、TSS 和最小用户代码及栈映射，接通 Ring 3 与 `int 0x80`。先验证用户程序通过 `sys_write` 输出，再接入 `sys_exit`。

异常入口和现场布局的当前实现见 [Trap 功能介绍](../architecture/trap.md)。

## 阶段目标

| 阶段 | 当前状态 | 验收观察点 |
| --- | --- | --- |
| 1. 环境与最小内核 | 已实现 Limine BIOS 启动和串口控制台 | `make test` 检查字符画、分级日志和最小内核启动。课程如要求自研 MBR，另行确认验收要求。 |
| 2. 异常、特权级与系统调用 | 已实现内核态断点异常往返 | `int3` 处理后继续执行。后续演示无效指令诊断，以及 Ring 3 的输出和退出。 |
| 3. 内存管理 | 已留接口 | 使用引导器内存映射初始化分配器，验证分配、释放和复用，再验证用户地址空间映射。 |
| 4. 任务与调度 | 已留接口 | 先观察两个任务协作让权，再接入时钟中断验证时间片轮转。 |
| 5. 同步与互斥 | 已留接口 | 实现锁及 P/V 信号量，用银行存取款演示检查并发更新的正确性。 |
| 6. 文件系统与 ELF64 | 已留接口 | 先验证读取文件和解析 ELF64 头，再演示装载用户程序。 |

GUI 帧缓冲与图形演示作为基础功能完成后的扩展方向。
