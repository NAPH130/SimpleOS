# SimpleOS 项目目录结构说明

## 当前状态

项目已具备最小内核、串口输出和 BIOS 启动镜像构建流程。后续子系统的接口声明集中在 `include/`，对应实现位置在 `src/`。`build/` 由构建过程创建，并由 `.gitignore` 排除。

## 目录职责

| 目录 | 职责 |
| --- | --- |
| `src/boot/` | 引导器配置和从引导环境进入内核的启动代码。具体文件取决于引导协议。 |
| `src/arch/x86_64/` | x86_64 特有的特权级、中断入口、上下文切换及底层指令封装。 |
| `src/kernel/` | 内核初始化、控制台、错误处理和系统调用等核心服务。 |
| `src/drivers/` | 串口、定时器等设备的驱动实现。 |
| `src/mm/` | 物理页帧、页表和内核堆等内存管理功能。 |
| `src/task/` | 任务和进程控制块、调度与生命周期管理。 |
| `src/sync/` | 自旋锁、互斥锁、信号量等同步原语。 |
| `src/fs/` | 文件和目录的组织与访问；初期可考虑简单的只读内存文件集合。 |
| `src/loader/` | 用户程序格式解析和装载，例如 ELF。 |
| `src/lib/` | 无宿主环境下供内核使用的基础工具。 |
| `include/` | 内核各模块共享的头文件，子目录与模块职责对应。 |
| `src/user/lib/` | 用户态程序使用的系统调用封装及基础运行支持。 |
| `src/user/apps/` | 独立编译的用户程序和演示程序。 |
| `tests/` | 按功能组织的测试，包括内存、调度和系统调用测试。 |
| `scripts/` | 构建镜像、运行与调试等辅助脚本。 |
| `docs/begin/`、`docs/steps/` | 项目设计、启动说明与分阶段实施指南。 |
| `docs/TEMP/` | 课程评分截图与其他班的参考实验材料。 |

## 预留接口

| 阶段 | 接口所在头文件 | 后续开发内容 |
| --- | --- | --- |
| 2 | `arch/x86_64/trap.hpp`、`arch/x86_64/context.hpp`、`kernel/syscall.hpp`、`user/syscall.hpp` | 异常和中断入口、特权级切换、系统调用分发及用户态封装。 |
| 3 | `mm/memory.hpp` | 接入引导内存映射，实现可变分区及内核堆，逐步加入物理页帧和虚拟地址空间管理。 |
| 4 | `task/scheduler.hpp`、`arch/x86_64/context.hpp` | 进程控制块、上下文切换、协作式让权和时钟抢占。 |
| 5 | `sync/primitives.hpp` | 自旋锁、阻塞式互斥锁和 P/V 信号量，供银行存取款并发演示使用。 |
| 6 | `fs/vfs.hpp`、`loader/elf.hpp` | 只读文件访问和 ELF64 程序装载。 |

每组接口旁有 `// TODO`。实现对应模块后，将内核 `.cpp` 文件添加到 `Makefile` 的 `SOURCES`，再接入 `kernel_main` 或相关调用点；用户态库和应用后续单独构建。当前 `make test` 验证串口格式化和最小内核启动。
