# 开发路线与阶段验收

当前基线是 Limine BIOS 启动、串口控制台和内核态 `int3` 自检。以下阶段目标用于安排开发，每一阶段准备可观察的运行结果。 [构建、运行与验证](../guides/getting-started.md)

## 近期任务

内核态异常入口、`#PF` 缺页诊断和 `#DF` 应急栈已通过 QEMU 自检。`make test-ring3` 已验证首次进入 Ring 3，以及用户态 `#UD` 使用 TSS 的 `RSP0` 切回内核。后续阶段包括接入系统调用和用于抢占式调度的定时器 IRQ。任务、依赖和验收项在 [Trap 开发计划](trap.md) 中维护。

## 阶段目标

| 阶段 | 当前状态 | 验收观察点 |
| --- | --- | --- |
| 1. 环境与最小内核 | 已实现 Limine BIOS 启动和串口控制台 | `make test` 检查字符画、分级日志和最小内核启动。课程如要求自研 MBR，另行确认验收要求。 |
| 2. 异常、特权级与系统调用 | 已验证内核态断点返回、故障诊断、应急栈和 Ring 3 换栈 | 用 QEMU 验证 `int3`、故障地址与错误码、`#DF` 切换 IST、Ring 3 异常切换 `RSP0`。后续演示用户态的输出和退出。 |
| 3. 内存管理 | 已留接口 | 使用引导器内存映射初始化分配器，验证分配、释放和复用，再验证用户地址空间映射。 |
| 4. 任务与调度 | 已留接口 | 先观察两个任务协作让权，再接入时钟中断验证时间片轮转。 |
| 5. 同步与互斥 | 已留接口 | 实现锁及 P/V 信号量，用银行存取款演示检查并发更新的正确性。 |
| 6. 文件系统与 ELF64 | 已留接口 | 先验证读取文件和解析 ELF64 头，再演示装载用户程序。 |

GUI 帧缓冲与图形演示作为基础功能完成后的扩展方向。
